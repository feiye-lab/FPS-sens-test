# 灵敏度匹配测试 · Sensitivity Match Test

给 **CS2** 和 **无畏契约（VALORANT）** 玩家用的鼠标灵敏度测试工具。单个 HTML 文件，无依赖，双击就能跑，数据不上传。

顶部切换游戏，两边的灵敏度和准星各存一份、互不覆盖。

## 它能回答什么

| 模式 | 回答什么 | 可信度 |
|---|---|---|
| **匹配度测试** | 当前灵敏度合不合手 | 只能判**有没有错配**和**往哪个方向**，给不出准确数值 |
| **灵敏度对比 A/B** | 两个灵敏度哪个表现更好 | **可信**，四维记分卡 + Holm 多重比较校正 |
| **新手找灵敏度** | 还没有固定值时该选哪个 | **可信**，2–4 档自定义扫描 |

> **先说清楚最重要的限制**：人在十几次甩枪内就会适应任何灵敏度。所以「匹配度」的信号只存在于最开始那几次里，它给不出一个精确的推荐值。要可信的推荐值，请用 A/B 对比或新手扫描——那两个模式比的是**适应之后的实际表现**。

## 测什么

甩枪落点 · 跟枪 · 微控 · 修正次数 · 波次清屏 · 转身行程 ·**压枪（仅 CS2）**

核心指标是**首次停枪的落点比值**：在灵敏度 S 下甩枪，落点 ÷ 目标角度 ≈ S/S\*，S\* 就是你运动皮层实际校准在的那个灵敏度。单次试验就是一个估计，所以不需要多档位扫描。

## 两个游戏差在哪

| | CS2 | 无畏契约 |
|---|---|---|
| 每计数转角 | 0.022° | 0.07° |
| FOV 模型 | Hor+，垂直恒定 73.7° | **固定** 103°×70.5°，不随比例变 |
| 4:3 拉伸铺满 | 牺牲视野换模型变宽 | **和 16:9 原生一模一样**，纯白拉 |
| 准星代码 | `CSGO-` base-57 分享码 | 分号分隔的键值串 |

灵敏度可以精确互换，物理不变量是 cm/360：

```
无畏契约灵敏度 = CS 灵敏度 × 0.022 / 0.07 = CS 灵敏度 ÷ 3.18182
```

DPI 在等式里自动抵消，所以换算与 DPI 无关。工具里的「按手感换算过来」按钮就是干这个的。

## 怎么用

1. 下载 `sens-test.html`，**在独立的 Chrome / Edge 窗口打开**
2. 选游戏 → 填你的 DPI 和游戏内灵敏度 → 粘贴准星代码（可选）
3. 选模式，开始
4. 测完可以导出 JSON

### 硬性要求

- **必须 Chrome / Edge**。Firefox / Safari 拿不到原始鼠标输入（`unadjustedMovement`），数据作废。
- **必须在独立浏览器窗口打开**。IDE 预览面板、侧边栏里会报 `WrongDocumentError`。
- 默认值是示例值，**第一次打开记得改成你自己的 DPI 和灵敏度**。

### 测不了的东西

浏览器事件时间戳分辨率是 1ms，所以 **≥1000Hz 的鼠标一律测成 1000Hz**，这是物理限制，不是能优化掉的 bug。要真正测高回报率必须读原生 HID。

## 关于诚实

这个工具刻意不做几件事：

- **不把估计器参数调到能还原你自称的灵敏度。** 那是拟合到假设，不是验证。
- **测不准就说测不准。** 习惯灵敏度反推会向你的输入收缩——同一只手（真实 43 cm/360）在五种设置下测，报出 60/49/43/40/36，方向永远对，但只还原真实差距的 62–82%。界面里标注为下限，不给一个看似精确的数字。
- **压枪的后坐力不是 AK 的真实弹道**，是有意的：真实弹道背得下来，而背下来的那套绑定在你当时那个灵敏度上，换灵敏度测就变成了考记忆而不是考灵敏度。

设计取舍、验证过程和已知缺陷都写在 [`sens-测试进展.md`](sens-测试进展.md) 里。
